Se programó el famoso juego del UNO siguiendo las reglas oficiales que contiene (emitiendo algunas que rara vez
se usan en la práctica), se hizo de forma gráfica (con el uso de imágenes y usando el lenguaje C#.
Actualmente el juego solo se juega de forma local de 4 jugadores, próximamente será implementado para ser jugado
en diferentes ordenadores y cada uno con su propia perspectiva.
El juego lleva un registro de jugadas, los jugadores que han participado y sus victorias o derrotas, todo eso
se sube a una base de datos de mySQL conectada mediante una API escrita en Python.
